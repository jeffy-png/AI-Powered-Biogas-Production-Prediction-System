AI-Powered Biogas Production Prediction System
------------------------------------------------

[Watch Project Demo on YouTube] https://youtu.be/kFbDSvZdPuI?si=WQ7lgmlVhC7pruYt

An AI-powered application that combines Machine Learning, Fuzzy Logic, and Generative AI to support biogas production prediction and intelligent analysis.

Project Overview
----------------

This project uses a trained Random Forest model to predict biogas production based on relevant input parameters. It also integrates Fuzzy Logic and Groq-powered Generative AI to provide additional insights and AI-assisted support.

Key Features
------------

Biogas Production Prediction: Predicts biogas production using a trained Random Forest model.

Fuzzy Logic Integration: Supports analysis using fuzzy logic techniques.

Custom Waste AI: Provides AI-assisted insights for different waste types.

AI Biogas Engineer: An AI-powered assistant for biogas-related queries.

Interactive Dashboard: User-friendly application built with Streamlit.

How It Works
------------

1. Input Parameters: Users provide the required biogas production parameters through the Streamlit application.

2. Data Processing: The input data is prepared in the required format for prediction.

3. Machine Learning Prediction: The trained Random Forest model processes the input parameters and predicts biogas production.

4. Fuzzy Logic Integration: Fuzzy Logic is incorporated to support the system's analysis.

5. Prediction Results: The application displays the predicted biogas production results through the interactive dashboard.

6. Custom Waste AI: Users can explore AI-generated insights related to different waste types using the Groq API.

7. AI Biogas Engineer: Users can interact with the AI assistant to ask biogas-related questions and receive AI-generated responses.

Technologies Used
-----------------
- Programming Language: Python
- Machine Learning: Random Forest
- AI Techniques: Fuzzy Logic
- Generative AI: Groq API
- Framework: Streamlit
- Data Processing: Pandas, NumPy
- Machine Learning Library: Scikit-learn
- Development Tools: VS Code, Google Colab
